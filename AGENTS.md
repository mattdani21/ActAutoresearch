# actautoresearch

Small single-product **pure-Python** repo: Karpathy's autoresearch loop pointed at the ASISA Standard on Effective Annual Cost (EAC) for a recurring-premium Retirement Annuity, instead of at a language model. See `README.md` and `program.md` for the design.

Core files: `prepare.py` (the EAC engine + the four acceptability gates, FIXED/read-only), `train.py` (the `CANDIDATE` charge structure the agent edits), `run.py` (the ratchet that scores a candidate and logs to `experiments.jsonl`), and `serve.py` (a stdlib dashboard).

## Cursor Cloud specific instructions

- This project is **plain CPU Python — it does NOT need a GPU.** The only third-party dependency is `scipy` (pulls in `numpy`); there is no `torch`/CUDA. Everything runs on the standard GPU-less Cursor Cloud VM. (Note: an earlier version of this repo was a GPU-based LLM trainer — that is gone; ignore any GPU/`torch` references.)
- Package manager is `uv`. It is installed at `~/.local/bin` but is **not guaranteed to be on `PATH` or persisted across fresh VMs**, and `/usr/local/bin` is not writable here. If `uv` is missing, reinstall with `curl -LsSf https://astral.sh/uv/install.sh | sh` and use `~/.local/bin/uv` (or `export PATH="$HOME/.local/bin:$PATH"`). The update script handles this automatically.
- Standard commands: `uv sync`, then `uv run prepare.py` (prints the baseline EAC table), `uv run train.py` (evaluates the current `CANDIDATE` against the gates), `uv run run.py` (the ratchet; `uv run run.py --demo` replays `candidates.py`).
- Dashboard: `uv run serve.py` serves `ui/` at http://localhost:8420 (stdlib only). It reads `experiments.jsonl`/`review_queue.jsonl`/`tracks.json` and records reviewer decisions to `decisions.jsonl`.
- There is no lint or automated test suite (no test framework, no linter config). "Validating" means running the commands above and eyeballing the EAC tables / gate verdicts, not running tests.
- Per `program.md`: only `train.py` is meant to be edited. `prepare.py` (the EAC metric and the G1–G4 gates) is read-only; do not monkey-patch or bypass `evaluate()`.
- Loop state files `best.json`, `decisions.jsonl`, `queue.jsonl` are gitignored and regenerated by `run.py`/`serve.py`/`ingest.py`.
